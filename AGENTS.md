# AgroCeans Twitch Hackathon

This repository is an isolated hackathon prototype.

## Safety rules
- Work only inside this repository.
- Never modify production AgroCoin, AgroWallet,
  STAMP, AgroCeans or Pinche Chess.
- Never commit credentials, private keys or tokens.
- Keep simulated activity clearly labeled.
- Never issue real AGRO or STAMP from demo events.
- Validate changes before committing.

## Development goals
1. Twitch environmental engagement overlay.
2. Twitch chat integration.
3. Secure real-time event bridge.
4. Reproducible setup and tests.
5. Public HTTPS demonstration.
